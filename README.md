## 🌟 ফিচারসমূহ (Features)

এই প্রজেক্টে **৭টি ভিন্ন ভিন্ন অপশন** আছে, প্রতিটির জন্য আলাদা ডিজাইন ও কাজ:

| # | অপশন | বর্ণনা |
|---|-------|--------|
| 1️⃣ | **সামনের ক্যামেরা (Front Camera)** | ছবি তুলে টেলিগ্রামে পাঠায় |
| 2️⃣ | **পিছনের ক্যামেরা (Back Camera)** | ছবি তুলে টেলিগ্রামে পাঠায় |
| 3️⃣ | **সামনের ভিডিও (Front Video)** | ৩০ সেকেন্ড রেকর্ড করে |
| 4️⃣ | **পিছনের ভিডিও (Back Video)** | ৩০ সেকেন্ড রেকর্ড করে |
| 5️⃣ | **কিবোর্ড ক্যাপচার (Keyboard)** | ইউজারের টাইপ করা টেক্সট ক্যাপচার |
| 6️⃣ | **লাইভ লোকেশন (Live Location)** | জিপিএস লোকেশন সংগ্রহ |
| 7️⃣ | **আইপি অ্যাড্রেস (IP Address)** | ইউজারের আইপি শনাক্ত |
